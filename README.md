# **PoE 2 Regex Builder**

A free community-built Regex Builder for Path of Exile 2, created by Vanguard805.

PoE 2 Regex Builder is designed to make finding the items you actually want faster and easier. Select an item type, choose the modifiers you care about, set any desired values or ranges, and the builder generates a compact regex ready to use in Path of Exile 2.

## **Website**

This repository contains the public website for PoE 2 Regex Builder.

The application itself is distributed separately as a compiled Windows executable through the project's GitHub Releases.

## **What It Does**

PoE 2 Regex Builder provides an interface for building searches without requiring users to manually write regex.

Features

- Compact Regex Generation — Modifier searches are shortened to conserve valuable regex characters.
- Smart Modifier Selection — Browse modifiers by item category and type.
- Numeric Filtering — Use Generic, Exact, At Least, At Most, and Range searches where supported.
- AND / OR Searches — Combine selected modifiers according to the type of search you need.
- Collision-Aware Regex — Compact expressions are designed to avoid matching unrelated affixes wherever possible.
- Wide Item Coverage — Supports weapons, armour, jewelry, offhands, jewels, tablets, waystones, and more.
- Defense Filtering — Armour, Evasion, and Energy Shield combinations can be selected for applicable equipment.
- Modifier Updates — Supported modifier information can be refreshed as game data changes.
- No Installation Required — Download the Windows executable and run it.

## **Reporting Issues**

If you encounter an incorrect regex, missing modifier, collision, or other problem, please report it through the project's GitHub issue tracker.

When possible, include:

- Application version
- Item category and type
- Modifier(s) selected
- Generated regex
- What was matched incorrectly or failed to match
- A screenshot

The more information provided, the easier the problem is to reproduce.
